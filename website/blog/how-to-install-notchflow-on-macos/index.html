How to Install NotchFlow on macOS

By Aditya Gupta • Published on November 3, 2026 • Tutorial • 5 min read

Installing software on modern macOS versions involves navigating Apple's Gatekeeper security verification, architecture checks, and privacy permissions. In this comprehensive tutorial, we cover three reliable methods to install NotchFlow on your Apple Silicon Mac.

Prerequisites

Before installing, confirm that your system meets the minimum requirements:

  • Mac Model: Any Apple Silicon Mac (M1, M2, M3, M4 or variant chips).
  • Operating System: macOS 14.0 Sonoma, macOS 15.0 Sequoia, or later.
  • Disk Space: At least 150 MB of available storage.

Method 1: Direct Disk Image (DMG) Installation

This is the official recommended method for most users:

  1. Download the official installer: NotchFlow-Installer.dmg from our homepage or GitHub Releases.
  2. Locate the file in your ~/Downloads folder and double-click to mount it.
  3. In the Finder window that appears, drag the NotchFlow icon onto the Applications folder shortcut.
  4. Wait for the copy process to complete, then right-click the mounted disk image on your desktop or sidebar and click Eject.

Method 2: Command Line Installation via Homebrew

If you maintain your Mac developer environment with the Homebrew package manager, you can install NotchFlow in a single terminal command: 

brew install --cask notchflow

Homebrew automatically downloads the latest release, verifies checksums, and places the application in /Applications. To update NotchFlow in the future: 

brew upgrade --cask notchflow

Method 3: Building from Source

For developers who prefer reviewing the Swift source code or compiling customized builds: 

# Step 1: Clone the repository
git clone https://github.com/Nightkilller/NotchFlow.git
cd NotchFlow

# Step 2: Build the release binary with SwiftPM
./build.sh release

# Step 3: Package into macOS .app bundle
./build.sh package

# The finished bundle will be located at:
# dist/NotchFlow.app

Configuring Initial macOS Permissions

When launching NotchFlow for the first time:

  1. Gatekeeper Prompt: Click Open when macOS asks to verify the newly downloaded application.
  2. Microphone Access: Click OK when prompted for microphone access. NotchFlow uses this exclusively for on-device speech tracking.

If you ever accidentally deny microphone permissions, you can re-enable them in System Settings > Privacy & Security > Microphone by toggling the switch next to NotchFlow.

Verifying the Installation

Launch NotchFlow from Spotlight (Cmd + Space > NotchFlow). Paste a short test sentence, click Start Teleprompter, and speak aloud. You should see the orange word highlight track your speech in real time.
