Installation Guide

Multiple ways to install and update NotchFlow on macOS.

Method 1: Direct DMG Download (Recommended)

The simplest and fastest method is to download the pre-compiled universal disk image:

  1. Download NotchFlow-Installer.dmg from our homepage or the official GitHub Releases page.
  2. Double-click the downloaded .dmg file to mount the disk image.
  3. Drag NotchFlow.app into the Applications shortcut folder.
  4. Eject the disk image from Finder.
  5. Open NotchFlow from Launchpad or Spotlight (Cmd + Space > NotchFlow).

Method 2: Homebrew Cask

For users who prefer managing software with Homebrew, you can install NotchFlow via terminal: 

brew install --cask notchflow

To update NotchFlow in the future via Homebrew: 

brew upgrade --cask notchflow

Method 3: Build from Source

If you want to contribute or inspect the codebase before running, you can compile NotchFlow directly from source using the Swift package manager: 

# 1. Clone the repository
git clone https://github.com/Nightkilller/NotchFlow.git
cd NotchFlow

# 2. Build release binary
./build.sh release

# 3. Package application bundle into dist/
./build.sh package

# 4. (Optional) Generate the drag-and-drop DMG installer
./build.sh dmg

The compiled application bundle will be generated in dist/NotchFlow.app.

macOS Gatekeeper Verification

Because NotchFlow is open-source software, macOS Gatekeeper may present an initial prompt asking if you wish to open the application downloaded from the internet. Click Open. If prompted with a security warning, open System Settings > Privacy & Security, scroll down to the Security section, and click Open Anyway.
