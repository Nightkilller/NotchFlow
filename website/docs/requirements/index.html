System Requirements

Detailed hardware, operating system, and permission requirements for NotchFlow.

Hardware Requirements

Component Requirement Notes
Processor Apple Silicon (M1, M2, M3, M4 or Pro/Max/Ultra variants) SpeechKit relies on Apple Neural Engine matrix coprocessors for sub-millisecond local speech evaluation. Intel Macs are not supported.
Memory (RAM) 8 GB unified memory or higher NotchFlow runs natively in Swift and typically consumes under 60 MB of RAM while active.
Storage ~150 MB free disk space Application bundle and local linguistic models.
Microphone Built-in MacBook microphone or any external audio input Works with USB microphones, AirPods, and studio XLR interfaces.

Operating System Requirements

  • macOS 14.0 Sonoma (Fully supported)
  • macOS 15.0 Sequoia (Fully supported)
  • macOS 13.x Ventura and older versions are not supported due to Swift 6 concurrency and SwiftUI APIs introduced in Sonoma.

Display Hardware Compatibility

  • MacBook Pro 14″ & 16″ (2021–present): Automatic safe-area geometry alignment around the camera notch.
  • MacBook Air 13″ & 15″ (2022–present): Automatic notch alignment around the M2/M3 camera cutout.
  • Notchless Macs & External Displays: Automatic top-center floating alignment with continuous rounded corners on Studio Display, Pro Display XDR, iMac, Mac mini, Mac Studio, or third-party 4K/1440p monitors.

System Permissions (TCC)

Under Apple's Transparency, Consent, and Control (TCC) security framework, NotchFlow requires one explicit permission:

  • Microphone Access (NSMicrophoneUsageDescription): Used exclusively to pace teleprompter scrolling to your live voice. No audio data leaves your device.
