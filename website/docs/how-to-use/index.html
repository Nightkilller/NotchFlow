How to Use NotchFlow

Complete user manual covering script editing, speech controls, window resizing, keyboard hotkeys, and theme toggling.

The Presentation Interface

NotchFlow is split into two primary operational modes:

  • Editor Window: A focused writing and script preparation environment where you compose, paste, or import documents.
  • Notch Pod Window: The floating, notch-aligned presentation bar that tracks your voice and displays your active script while presenting.

Keyboard Shortcuts Reference

While presenting, you can control NotchFlow hands-free with your voice or using standard keyboard shortcuts:

Shortcut Function Description
Space Play / Pause Toggle speech tracking and manual scrolling.
← / → Step Word Move highlight backward or forward by one word.
↑ / ↓ Jump Sentence Jump backward or forward by one complete sentence.
R Reset Rewind script back to the very beginning.
+ / - Speed Adjustment Increase or decrease auto-scroll speed factor.
[ / ] Font Size Increase or decrease reading typography size.
D Debug HUD Toggle confidence scores, speech buffer, and metrics HUD.
Esc Dismiss Close the prompter pod and return to the main editor.

Resizing the Teleprompter

Hover your pointer over any border or corner of the NotchFlow prompter window. When the cursor changes to a resize indicator, click and drag:

  • Horizontal Width: Range between 380 pt and 950 pt.
  • Vertical Height: Range between 180 pt and 650 pt.

NotchFlow automatically saves your dimension preferences and restores them the next time you launch a teleprompting session.

Switching Themes

In the prompter controls or main editor, click the theme button to switch between:

  • Pure Black (#000000): Deep contrast theme designed for dimly lit rooms and subtle camera camouflage.
  • Studio White (#FFFFFF): Clean daylight theme designed for high-ambient office and studio lighting.

Mirror Mode

If you mount your MacBook underneath a professional 70/30 teleprompter glass beam-splitter rig, enable Mirror Mode from the settings menu. This flips the script horizontally so it reads normally when reflected through optical glass.
